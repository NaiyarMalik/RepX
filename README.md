# RepX

**RepX** is a handheld grip rep counter designed to automatically count hand-gripper repetitions.

## Current Status

![Define Problem]([https://img.shields.io/badge/Status-Complete-brightgreen](https://img.shields.io/badge/Verilog-✓-brightgreen)) 
![Select Components](https://img.shields.io/badge/Status-Complete-brightgreen)


## Why I Made This

I do hand-gripper exercises at home and sometimes in class, but I always end up **counting reps wrong or forgetting what rep I'm on**.

RepX solves this by automatically detecting each squeeze and keeping track of the number of repetitions.

## Current Progress

🔧 **Prototype 1 — Currently soldering**

The first hardware prototype is currently being assembled and soldered. The goal is to test the sensor, microcontroller, and display together before moving toward a more refined version.

## Planned Features

- Automatic rep detection
- Live rep count
- Small, portable form factor
- Battery powered
- Designed to attach to a hand gripper

## Tech

- **Microcontroller:** ATtiny1616
- **Sensor:** Hall effect sensor
- **Display:** 7-segment display
- **PCB:** Custom PCB designed in Altium
- **Enclosure:** 3D printed
